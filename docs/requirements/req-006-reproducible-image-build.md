# REQ-006 — Reproducible image build and Outfitter settings

The image **MUST** be built and loaded through repository scripts backed by the Nix flake. Node-based tools **MUST** be pinned/materialized by Nix and **MUST NOT** require checked-in `package.json` or `package-lock.json` files. Runtime Podman orchestration **MUST NOT** live in the flake; the launcher script **MUST** use the prebuilt tagged image. The launcher **SHOULD** provide explicit flag-based update and replacement paths, such as `--update`, `--outfitter-version VERSION`, and `--replace`, that update flake inputs, bump the pinned Outfitter npm package, rebuild/load the tagged image, and recreate the workspace pod so the updated image is used without requiring control environment variables. The launcher **MUST** materialize a host Outfitter root, defaulting to `$HOME/.outfitter/zejent/root`, and mount it to `/root/.outfitter`. That root **MUST** include the local Link `.outfitter` checkout plus the Zejent profile and system prompt, and **MUST NOT** require cloning private Link profiles from inside the container at runtime.
