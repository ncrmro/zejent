# REQ-007 — Zellij layout

A new session **MUST** open visible tabs named `lazy-git` and `leader-agent`. Tabs started by agents for subagent tasks **MUST** use a tab name matching the subagent/task name. Each such tab **MUST** launch Outfitter/Pi with a stable `--session-id` derived from the workspace identity plus task/subagent name, and **SHOULD** also pass `--name` with the same human-readable task name. When a `TASK.md` file exists in the worktree, tab names and Pi session names **SHOULD** incorporate the task identifier or title from that file. Zellij layouts and pane helper scripts **MUST** be source-controlled image inputs rather than large inline flake strings. The `leader-agent` command **MUST** be configurable, and **SHOULD** default to the Zejent Outfitter/Pi profile with stable session identity.
