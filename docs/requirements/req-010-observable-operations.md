# REQ-010 — Observable operations

The launcher **SHOULD** print the resolved workspace, pod/container name, Zellij session name, rendered Kubernetes YAML path, mounted Outfitter root path, GitHub secret name, Pi home mount, persistent `/tmp` volume name, Pi session directory, leader Pi session ID, and leader Pi session display name before attaching. Background pods/containers **SHOULD** be labeled so they can be listed and managed with `podman pod ps --filter label=dev.ncrmro.agent.kind=nix-zellij` or `podman ps --filter label=dev.ncrmro.agent.kind=nix-zellij`. Zejent **MUST** include a manual or scripted validation path showing that detach/relaunch preserves tabs, pod restart behavior matches the documented expectation, Outfitter/Pi setup is not unnecessarily repeated, no `/root/.pi` `EROFS` regression occurs, and Pi session resume still works via stable `--session-id`.
